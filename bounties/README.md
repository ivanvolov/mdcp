# Bounties

One folder per sponsor we submit to. Each holds the **paperwork** for that
bounty — the prize text as it applies to us, a qualification evidence map, the
draft submission answers, the demo beats, and a TODO of what is still missing.

The **code and benchmark artifacts stay where they live** (`app/`, `skills/`,
`BENCHMARK.md`). They are shared across bounties — the same gateway serves
Uniswap, Hedera and The Graph — so copying them here would fork the truth four
hours before a deadline. Each bounty folder instead carries an artifact map
pointing at the real files.

ETHGlobal lets one project select **3 partner prizes** at submission. The picks
are a single decision across all folders here; see each TODO for its ask.
